# Project Germania screenshots

Store curated V2.0 release screenshots in this directory.

Before committing an image:

- remove credentials, personal information, local filesystem paths, and private database details;
- use an optimized PNG, WebP, or JPEG;
- prefer one desktop overview and one responsive-width example per major workflow;
- describe the page, capture date, data provenance, and whether values are source data or derived metrics;
- do not copy automated browser-validation output directly from `reports/`.

Suggested names:

```text
executive-overview.png
vehicle-peer-benchmark.png
global-intelligence-hub.png
search-center.png
data-quality.png
```
